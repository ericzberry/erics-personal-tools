# erics-personal-tools

Personal Mac configuration and tooling for Eric Berry.

## What's here

| Folder | What it is |
| --- | --- |
| [`chrome-sidebar/`](./chrome-sidebar) | Personal Chrome sidebar — saved ESPN league rules and draft-pick tracking; sync server TBD. |
| [`mac-customization/`](./mac-customization) | Mac setup — Hammerspoon config (per-space labels, auto-launch managed apps, window placement). More tooling will land here over time. |

More to come.

## Setup on a new Mac

```sh
git clone git@github.com:ericzberry/erics-personal-tools.git ~/erics-personal-tools
```

Then follow the README in each subfolder for that tool's specific install steps.
