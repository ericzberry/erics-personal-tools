# Eric’s Personal Tools privacy policy

Updated September 9, 2026. Applies to version 0.6.34, including the AI connection settings page.

Eric’s Personal Tools displays contextual assistance alongside ESPN and Gmail. It checks the active tab’s URL to select the appropriate function; it does not retain browsing history.

In ESPN football draft rooms, the extension reads visible selections, team names and identifiers, league and season identifiers, draft order and progress. Captured sessions are stored in Chrome extension storage on your device. The extension retains up to ten practice sessions and the configured league session.

In Gmail, the sidebar reads the latest expanded message’s subject, sender and rendered text. Reading alone does not upload the email. Clicking Summarize sends that message through the owner’s HTTPS Worker to OpenAI, using the API key decrypted from D1. The app does not persist email content or summaries in D1 or Chrome storage; the OpenAI Responses request sets store:false. Cloudflare and OpenAI process the request under their own policies. Reply drafts continue to use Chrome’s on-device AI, which may download its model before first use. Generated text remains in sidebar memory until you copy it or change messages. Clipboard handling follows your device settings.

The extension does not transmit draft data, sell data, use analytics, or automatically submit draft picks or email. Email text is sent only when you click Summarize. The personal settings page sends AI connection names, providers, model IDs, optional API URLs and API keys through the extension to the owner’s Worker at erics-tools-api.ezberry.workers.dev. These settings are encrypted before storage in D1 using a separate Worker encryption secret. Cloudflare processes the HTTPS requests and server-side plaintext during encryption/decryption. Saved keys are not returned to the page; responses indicate only whether a key is saved. When you click Fetch models, Test connection or Run prompt, the Worker sends the appropriate request to the saved AI provider. Tests send a fixed short prompt; Run prompt sends the text and optional instructions you enter. The provider key is decrypted in the Worker and sent directly to that provider for authentication. API responses return through the extension. Prompts and generated responses remain in page memory; this app does not persist them in D1 or Chrome storage. AI providers process requests under their own retention and billing policies. Redirects are not followed, and provider errors are summarized without reflecting credential values. Cloudflare processes network requests under its own policies. Links to ESPN or Gmail open those services under their own policies.

Exporting draft history creates a local JSON file. You control subsequent sharing. Rankings are bundled statically. Custom ranking and projection data saved by older versions is no longer read. Uninstalling clears extension storage, including the local cloud access token; exported files, saved cloud settings and copied text remain until deleted. Disconnect removes the access token from the browser but leaves cloud settings. Use Remove connection on the settings page to delete an AI connection and its key. Any backup created with the previous experimental backup implementation remains in the D1 records table until removed through the owner’s dashboard; the backup endpoint is no longer accessible in this version. The connection token is stored locally with access restricted to trusted extension contexts. Draft storage is not synced across computers.

This version declares all-site host permission at the owner’s request for planned personal tools. Current page-reading scripts run only in ESPN football draft rooms and Gmail. Other sites are not read beyond identifying the active tab’s URL to select a function.

Manual draft corrections are saved locally, separately for each draft session, and used only when manual mode is active. The extension bundles a public ESPN player catalog and offers a refresh that requests public player and NFL team data from ESPN without cookies. These requests do not include your draft, rankings, or email content. Refreshed player identities are cached locally.

Recommendations are passed locally to the captured ESPN draft tab via draft-capture responses and sidebar updates to highlight matching visible players. This does not submit selections or send draft data to an external server. Highlights expire when draft-capture and sidebar updates stop.

The contextMenus permission adds a webpage right-click launcher. Clicking it opens the sidebar in that Chrome window; the launcher does not store or transmit the clicked page, link, or selected text.

Credentials entered in Settings are stored in local Chrome extension storage, restricted to trusted extension contexts. They are not encrypted by the extension, synced, exported with draft diagnostics, or transmitted to a provider. Saved keys are not displayed in the credential list. You can replace or delete them; uninstalling clears extension storage. Saving a key does not yet activate a service integration.

Sidebar Credentials now uses the same encrypted D1 connections. On connection or refresh, supported legacy local keys are uploaded over HTTPS and removed locally only after a confirmed save. Unrecognized keys and failed or conflicting transfers remain local for review. New sidebar keys are never saved locally. The Worker access token remains in trusted local storage.
